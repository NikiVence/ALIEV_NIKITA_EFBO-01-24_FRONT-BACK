📱 О приложении

Todo PWA - это прогрессивное веб-приложение для управления задачами с полной офлайн-поддержкой.

✨ Возможности:

  • Работа без интернета
  • Установка на рабочий стол
  • Мгновенная загрузка (App Shell)
  • Push-уведомления
  • Фоновая синхронизация
  • Защищенное HTTPS соединение

🛠 Технологии:

HTML5 CSS3 JavaScript (ES2020) Service Worker API Web App Manifest Cache API localStorage

📊 Статистика:

⚡ 100% Lighthouse PWA 📦 Размер: ~50KB 🔄 Автообновление
